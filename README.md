# CCTV Project

Небольшое веб-приложение для работы с источниками видеонаблюдения. Приложение позволяет просматривать список источников и управлять их данными через веб-интерфейс.

## О проекте

Проект создан для работы с источниками видеонаблюдения и демонстрирует взаимодействие пользовательского интерфейса, серверной части и базы данных.

Приложение состоит из нескольких частей:
- **Frontend** — пользовательский интерфейс на Vue.js.
- **Backend** — серверная часть на FastAPI.
- **Database** — PostgreSQL для хранения данных.

Проект разрабатывался в учебных целях, чтобы получить практический опыт создания веб-приложений, работы с API, базами данных и контейнеризацией.

## Используемые технологии

- Python
- FastAPI
- Vue.js
- Node.js
- PostgreSQL
- Docker
- Docker Compose

## Структура проекта

- `frontend/` — клиентская часть приложения.
- `backend/` — серверная часть приложения.
- `docker-compose.yml` — конфигурация запуска сервисов.


## Статус проекта

Проект находится в разработке. В настоящее время выполняется настройка запуска через Docker и проверка работы компонентов приложения.

## Автор

Учебный проект.
