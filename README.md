CCTV Project

Небольшой веб-проект для работы с источниками видеонаблюдения. Приложение позволяет просматривать список источников и управлять их данными через веб-интерфейс.

О проекте

Проект состоит из двух частей:

Frontend — пользовательский интерфейс на Vue.js.

Backend — серверная часть на FastAPI.

Database — PostgreSQL для хранения данных.

Приложение разрабатывалось как учебный проект, чтобы на практике разобраться с созданием веб-приложений, взаимодействием frontend и backend, работой с базой данных и запуском сервисов через Docker.

Используемые технологии

Python

FastAPI

Vue.js

Node.js

PostgreSQL

Docker и Docker Compose

Запуск проекта

Для запуска понадобятся установленный Docker и Docker Compose.

Склонируйте репозиторий:

git clone <ссылка-на-репозиторий> 

Перейдите в папку проекта:

cd cctv_project 

Соберите и запустите сервисы:

docker compose up --build 

После запуска frontend и backend должны быть доступны по адресам, указанным в настройках Docker Compose.

Статус проекта

Проект находится в разработке. Сейчас основное внимание уделяется настройке запуска через Docker и проверке работы всех компонентов.
